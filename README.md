# Import-Organizer

Organize import statements

## Features

- Easy-to-use CLI interface
- Fast and efficient processing
- Cross-platform support

## Installation

```bash
git clone https://github.com/Qyroxen/Import-Organizer.git
cd Import-Organizer
go build -o import-organizer .
```

## Usage

```bash
.import-organizer .
.import-organizer --path ./src
```
